# Yali-Project

Yali-Project is an open-source organization built around Yali High School.  
We build tools for real teaching and campus life, and we open them up for everyone.

## What we build

We don't have any curated GitHub repositories yet - join us and be the first contributor to fill this blank out!

## Get involved

- Found a bug or have an idea? Open an issue in the relevant repository.
- Want to contribute? Start with the issues and each project's README.
- Using these tools? You are welcome to, and we would love to hear how they work in real scenarios.

## About us

Yali-Project is maintained by teachers, students, and contributors connected to Yali High School.  
We believe small tools that are actually used on campus are worth open-sourcing properly.
